# اتوماسیون سئو و تولید محتوا

هر **۲ روز** (قابل‌تغییر از داشبورد) یه مقاله‌ی سئوشده‌ی جدید خودکار توی وبلاگ منتشر می‌شه.

## چطور کار می‌کنه
1. **پیدا کردن کلمه‌ی کلیدی** — از موضوع‌های اصلی سایت (صفحه‌های خدمات + «سایت <صنف>» برای همه‌ی صنف‌ها) چند تا به‌صورت تصادفی
   انتخاب می‌شه و پیشنهادهای جستجوی گوگل (autocomplete) براشون گرفته می‌شه؛ یعنی عبارت‌هایی که مردم واقعاً سرچ می‌کنن.
   کلمه‌های جدید توی صف `seo_keywords` می‌رن.
2. **نوشتن مقاله** — Claude (`claude-opus-5-5`) از صف بهترین کلمه رو انتخاب می‌کنه (بی‌ربط‌ها رو رد می‌کنه، موضوع تکراری با
   مقاله‌های قبلی نمی‌نویسه) و مقاله‌ی ۱۲۰۰ تا ۱۸۰۰ کلمه‌ای می‌نویسه: کلمه‌ی کلیدی در عنوان، پاراگراف اول و تیتر، متا دیسکریپشن
   ۱۲۰–۱۶۰ کاراکتر، تیترهای ##/###، لیست، بخش سوالات متداول، بدون آمار و نقل‌قول ساختگی.
3. **لینک‌سازی داخلی**
   - مقاله‌ی جدید ۳ تا ۶ لینک توی متن داره: به صفحه‌های خدمات (`lib/landingPages.ts`) و مقاله‌های قبلی مرتبط.
   - هر لینکی که به یه صفحه‌ی واقعی سایت نباشه (یا لینک خارجی) خودکار به متن ساده تبدیل می‌شه.
   - مقاله‌ی جدید یه بخش «مطالب مرتبط» با ۳ مقاله‌ی مرتبط می‌گیره و **همون ۳ مقاله‌ی قبلی هم** توی «مطالب مرتبط» خودشون به مقاله‌ی جدید
     لینک می‌گیرن (حداکثر ۶ لینک، جدیدترین اول).
   - لینک‌های داخلی توی همون تب باز می‌شن.
4. **انتشار** — مستقیم منتشر می‌شه، توی sitemap میاد و اجرا توی تب «اتوماسیون سئو» ثبت می‌شه.

## راه‌اندازی (یک بار)
توی Vercel ← Settings ← Environment Variables:
- `ANTHROPIC_API_KEY` — کلید API از console.anthropic.com
- `CRON_SECRET` — یه رشته‌ی تصادفی طولانی (Vercel خودش موقع صدا زدن کرون می‌فرسته)

بعد دوباره دیپلوی کن. کرون (`vercel.json`) هر روز ساعت ۰۵:۱۷ UTC (حدود ۸:۴۷ تهران) اجرا می‌شه و خودش چک می‌کنه نوبت مقاله‌ی بعدی رسیده یا نه.
تابع تا ۳۰۰ ثانیه وقت داره (`maxDuration`).

## داشبورد ← «اتوماسیون سئو»
- روشن/خاموش و فاصله‌ی بین مقاله‌ها (روز)
- «الان یه مقاله بساز» برای اجرای دستی
- صف کلمه‌های کلیدی (رد کردن، برگردوندن، اضافه کردن دستی)
- لیست اجراها با لینک مقاله یا متن خطا

فایل‌ها: `lib/seoAutomation.ts`، `app/api/cron/seo/route.ts`، `app/dashboard/SeoAutomationPanel.tsx`، `vercel.json`.
