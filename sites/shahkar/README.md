# سایت باغچه رستوران شاهکار

سایت مستقل Next.js (React 19) + Node.js + SQLite با انیمیشن‌های GSAP و Motion — تم مشکی و طلایی.

## اجرا

```bash
cd sites/shahkar
npm install
cp .env.example .env.local   # و ADMIN_PASSWORD را عوض کنید
npm run dev                  # http://localhost:3100
```

نسخه‌ی production:

```bash
npm run build && npm start
```

نیازمند Node.js 20 به بالا. فونت‌ها داخل خود پروژه هستند (بدون Google Fonts)، پس داخل ایران هم بدون مشکل لود می‌شن.

## بخش‌ها
- **لودر «در باغ»**: نشان طاق و فانوس خودش رو می‌کشه، اسم شاهکار ظاهر می‌شه و دو لنگه در باغ باز می‌شن (GSAP)
- **هیرو**: عکس واقعی باغ، ردیف فانوس‌های تاب‌خور که به حرکت ماوس واکنش نشون می‌دن، کرم‌های شب‌تاب طلایی (canvas)، پارالاکس اسکرول
- **امتیازها**: ۵ ویژگی (تمام‌وقت، پارکینگ، غذای ایرانی، موسیقی زنده، حضور هنرمندان) با کارت‌های سه‌بعدی
- **از سالن تا باغ**: گالری افقیِ پین‌شده (روی موبایل عمودی) با عکس‌های داخل سالن و باغ
- **منو**: از دیتابیس SQLite خونده می‌شه، با تب‌های انیمیشنی (قیمت اختیاری؛ از پنل اضافه می‌شه)
- **موسیقی زنده**: پس‌زمینه‌ی «پرده‌ی نور» شبیه صحنه‌ی واقعی رستوران که به ماوس واکنش می‌ده
- **مراسم**، **گالری با لایت‌باکس**، **فرم رزرو** (ذخیره در SQLite + ارسال خلاصه در واتساپ)، **نقشه‌ی مسیر انیمیشنی**، فوتر

## پنل مدیریت — `/admin`
با `ADMIN_PASSWORD` وارد می‌شید:
- لیست درخواست‌های رزرو، تغییر وضعیت (جدید / تأیید / انجام شده / لغو)، تماس و واتساپ مستقیم با مشتری
- مدیریت منو: افزودن غذا (با قیمت اختیاری)، مخفی/نمایش، «پیشنهاد سرآشپز»، حذف

## دیتابیس
فایل `data/shahkar.db` (یا مسیر `SQLITE_PATH`) اولین بار خودکار ساخته می‌شه و منوی نمونه داخلش ریخته می‌شه.
این فایل در git نیست؛ موقع دیپلوی روی سرور، از پوشه‌ی `data/` بکاپ بگیرید.
روی سرورهای serverless (مثل Vercel) فایل SQLite دائمی نمی‌مونه؛ برای این سایت سرور/VPS با Node لازمه (مثلاً با `pm2 start npm -- start`).

## فایل‌ها
- `lib/site.ts` — اطلاعات کسب‌وکار (تلفن، واتساپ، اینستاگرام، آدرس)
- `lib/db.ts` — اسکیمای SQLite، منوی اولیه، کوئری‌ها
- `app/api/reservations/route.ts` — ثبت رزرو (اعتبارسنجی، honeypot ضد اسپم، محدودیت تعداد درخواست)
- `app/admin/` — پنل مدیریت
- `components/` — بخش‌های سایت
- `public/images/` — عکس‌های محیط (webp، دو اندازه)

## نسخه‌ی تک‌فایلی HTML
`private-sites/shahkar.html` — کل سایت در یک فایل (فونت‌ها و عکس‌ها داخلش، بدون نیاز به سرور یا اینترنت).
همه‌ی انیمیشن‌ها با JS/CSS ساده بازنویسی شده‌اند؛ چون دیتابیس ندارد، فرم رزرو پیام آماده را در واتساپ باز می‌کند.
برای ساخت دوباره (بعد از تغییر سایت یا منو): سایت را اجرا کنید (`npm run build && npm start`) و بعد:

```bash
node scripts/export-html.mjs
```
