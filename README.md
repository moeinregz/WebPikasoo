# تغییرات — تب «نمونه‌کارها» تو داشبورد ادمین

## کاری که انجام شد

تب «نمونه‌کارها» به داشبورد اضافه شد با ۵ فیلد که خواسته بودی:

1. **عنوان**
2. **دسته‌بندی** (انتخابی، از همون لیست دسته‌بندی‌های سایت)
3. **توضیحات**
4. **عکس** — آپلود فایل (ترجیحاً WebP)، نه لینک
5. **فایل سایت** — یا یه فایل HTML آپلود می‌کنی (که رو خودِ سایتت باز می‌شه، آدرس `/portfolio/view/شناسه`)، یا یه لینک می‌دی (که به دامنه‌ی خودش می‌ره). فقط یکی از این دو رو باید پر کنی.

نمونه‌کارها همون‌جایی نمایش داده می‌شن که الان صفحه‌ی «نمونه‌کارها»ی سایتت (`/portfolio`) و بخش نمونه‌کارهای صفحه‌ی اصلی نمایش می‌دن — چیز جدیدی برای نمایش عمومی لازم نبود، چون اون بخش از قبل به همین دیتابیس وصل بود.

## یه مشکل قدیمی که پیدا و درست شد

فایل `lib/businessSites.ts` از پروژه‌ای که آپلود کردی **حذف شده بود** ولی چند تا فایل دیگه (`app/page.tsx`, `app/portfolio/page.tsx`, `ProjectsPanel.tsx`) بهش نیاز داشتن — یعنی پروژه اصلاً بیلد نمی‌شد. از تاریخچه‌ی گیت پروژه بازش گردوندم؛ محتواش دست نخورده باقی مونده (فقط لیست دسته‌بندی‌ها و سایت‌های نمونه‌ی قدیمی).

همچنین کامپوننت `ProjectsPanel.tsx` از قبل تو پروژه بود ولی اصلاً به تب‌های داشبورد وصل نشده بود — یعنی این ویژگی نصفه ساخته شده بود و هیچ‌جا دیده نمی‌شد. الان کامل و وصل شد.

## فایل‌های تغییر/اضافه شده (این پوشه دقیقاً همینا رو داره، مسیرشونم حفظ شده)

**تغییر یافته:**
- `lib/uploads.ts` — دو تابع جدید: `saveProjectImage` (آپلود عکس نمونه‌کار) و `saveProjectHtmlFile` (آپلود فایل HTML)
- `lib/db.ts` — فیلد `linkType` ("url" یا "html") به مدل Project اضافه شد، تابع `getProjectById` و دسترسی جدید `projects` برای اعضای تیم
- `lib/businessSites.ts` — بازگردانی فایل گم‌شده
- `app/dashboard/AccessPanel.tsx` — گزینه‌ی دسترسی «نمونه‌کارها» به تب دسترسی‌ها اضافه شد
- `app/dashboard/actions.ts` — منطق ذخیره‌سازی: آپلود عکس، آپلود/اعتبارسنجی فایل HTML یا لینک
- `app/dashboard/ProjectsPanel.tsx` — فرم و لیست نمونه‌کارها بازنویسی شد
- `app/dashboard/page.tsx` — تب «نمونه‌کارها» وصل شد
- `app/page.tsx` و `app/portfolio/page.tsx` — لینک نمایش نمونه‌کار حالا از تابع مشترک `projectViewUrl` می‌گیرن

**فایل جدید:**
- `lib/projectLink.ts` — تابع کوچیک `projectViewUrl` که مشخص می‌کنه لینک «مشاهده» باید به کجا بره (owned by us for html files را از `/portfolio/view/[id]` می‌فرسته، وگرنه مستقیم لینک خارجی)
- `app/portfolio/view/[id]/route.ts` — روتی که فایل HTML آپلودشده رو از Vercel Blob می‌گیره و مستقیم روی دامنه‌ی خودت (نه دامنه‌ی Blob) نمایش می‌ده؛ برای نمونه‌کارهای لینک‌دار هم ریدایرکت می‌کنه

## طرز اعمال کردن

هر فایل رو با همون مسیر نسبی که تو این پوشه داره، جایگزین/اضافه کن تو پروژه‌ی اصلیت (روی همون مسیرها). چیز دیگه‌ای لازم نیست — از همون `BLOB_READ_WRITE_TOKEN` و `MONGODB_URI` که از قبل تو پروژه ست شده استفاده می‌کنه، نیازی به متغیر محیطی جدید نیست.

تایپ‌اسکریپت کل پروژه رو با `tsc --noEmit` چک کردم و بدون خطا رد شد.
