# راهنمای ادمین — «باقلوا کریم اغلو»

## اولین ورود (فقط یک‌بار، بعد از اولین Deploy Production)

1. مطمئن شوید هنگام اولین بالا آمدن Production، `KARIMOGLU_BOOTSTRAP_ADMIN_MOBILE` و `KARIMOGLU_BOOTSTRAP_ADMIN_PASSWORD` در Secrets تنظیم شده بودند (رجوع به `environment-variables.md`) — در غیر این صورت **هیچ حساب ادمینی وجود نخواهد داشت** (طبق اصلاح امنیتی Prompt 13، دیگر رمز پیش‌فرض شناخته‌شده در Production ساخته نمی‌شود).
2. با همان موبایل/رمز به `/admin` وارد شوید.
3. **بلافاصله** رمز عبور را از پنل عوض کنید و مقدار `KARIMOGLU_BOOTSTRAP_ADMIN_PASSWORD` را از GitHub Secrets حذف کنید — دیگر لازم نیست و نگه‌داشتنش فقط ریسک است.
4. برای هر عضو واقعی تیم (مدیرعامل، مدیران شعب، انبار، صندوقدار)، یک حساب جدا با نقش مناسب بسازید (بخش ۱۰ Prompt‌های قبل) — از اشتراک‌گذاری همان حساب Bootstrap بین چند نفر خودداری کنید.

## نقش‌ها (رجوع به Prompt‌های قبل برای تعریف کامل)

| نقش | دسترسی خلاصه |
|---|---|
| `site_admin` | کامل — از جمله مدیریت کاربران/نقش‌ها |
| مدیران شعب | TBD طبق Context اولیه پروژه — هنوز نقش دقیق تعریف نشده در کد فعلی، همان `site_admin` موقت استفاده می‌شود مگر تیم نقش جدا بخواهد |
| `warehouse_staff` | موجودی/انبار |
| `cashier` | مشاهده سفارش، موجودی |

## عملیات حساس (همه در `audit_log` ثبت می‌شوند)

- تغییر قیمت/موجودی/وضعیت سفارش
- تغییر نقش کاربران
- تنظیمات (Settings)
