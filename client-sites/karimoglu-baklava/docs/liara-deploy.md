# راهنمای دیپلوی روی لیارا — پلتفرم NodeJS + PostgreSQL

این پروژه فقط به **یک دیتابیس PostgreSQL** وابسته است (کاربران، سفارش‌ها، موجودی، نظرات،
تنظیمات، حتی عکس‌های آپلودشده). دیسک یا Volume لازم نیست.

## قدم‌ها
1. `npm install` روی کامپیوتر خودتان (برای به‌روز شدن `package-lock.json`)، سپس `npm test` و `npm run dev`.
2. در لیارا یک اپ **NodeJS** بسازید (و یک دیتابیس PostgreSQL در همان حساب).
3. در پنل اپ ← تنظیمات: **فایل‌سیستم** را از «ReadOnly» به «Writable» تغییر دهید
   (Next.js موقع اجرا فایل‌های موقت می‌نویسد؛ چون همه داده‌ها در PostgreSQL است، از دست رفتن
   این فایل‌های موقت با Restart مشکلی ایجاد نمی‌کند).
4. متغیرهای محیطی را بگذارید: `DATABASE_URL` (آدرس **داخلی** دیتابیس)،
   `KARIMOGLU_BOOTSTRAP_ADMIN_MOBILE`، `KARIMOGLU_BOOTSTRAP_ADMIN_PASSWORD`.
   (فقط در صورت خطای SSL با آدرس بیرونی: `PG_SSL=true`).
5. در `liara.json` مقدار `app` را به نام اپ خود تغییر دهید، سپس `liara deploy`
   (یا زیپ بدون `node_modules`/`.next`/`.env` را در «استقرار جدید ← Drag & Drop» آپلود کنید).
6. `/api/health/ready` را باز کنید؛ پاسخ `ok` یعنی اتصال به دیتابیس برقرار است.

جدول‌ها و داده پایه (کاتالوگ، شعب، موجودی اولیه، نقش‌ها، حساب ادمین) در **اولین درخواست**
خودکار ساخته می‌شوند و فقط وقتی دیتابیس خالی باشد.
