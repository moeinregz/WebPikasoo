# سایت‌های اختصاصی (خصوصی)
فایل‌های HTML تک‌فایلی که برای یک مشتری خاص ساخته شدن. این پوشه عمومی سرو نمی‌شه؛
برای انتشار، فایل رو از داشبورد ← تب «سایت‌های خصوصی» آپلود کن تا لینک `/preview/<توکن>` بگیره.

| فایل | کسب‌وکار |
| --- | --- |
| `milla-mode.html` | میلا مُد (Milla Mode) — خرید اورجینال برندهای جهانی از ترکیه؛ واتساپ ۰۹۳۰۵۸۹۳۷۰۷، بله @millamode |
