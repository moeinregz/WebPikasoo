# ممد قهوه — فروشگاه آنلاین قهوه

Next.js 14 (App Router) + React 18 + Node.js + SQLite (better-sqlite3)

## راه‌اندازی

```bash
cd mamad-ghahve
npm install
cp .env.example .env.local     # SITE_URL و رمز ادمین رو عوض کن
npm run build
npm start                       # http://localhost:3000
```

دیتابیس (`data/shop.db`) اولین بار خودکار ساخته و با محصولات نمونه پر می‌شه.
پنل مدیریت: `/admin` — ورود اول با `ADMIN_USERNAME` / `ADMIN_PASSWORD` از `.env.local` (پیش‌فرض `admin` / `admin123`). بعد از ورود از «تنظیمات» رمز رو عوض کن.

> روی سرور (VPS) اجرا کن، نه هاست‌های serverless مثل Vercel؛ SQLite و عکس‌های آپلودی روی دیسک ذخیره می‌شن (`data/`). از پوشه‌ی `data/` بکاپ بگیر.

## امکانات

**فروشگاه**
- اسلایدر هیرو با جابه‌جایی خودکار هر ۳ ثانیه، نقطه‌ها، فلش‌ها و سوایپ روی گوشی
- ردیف‌های «جدیدترین‌ها»، «محبوب‌ترین‌ها» (بر اساس تعداد فروش)، «تخفیف‌های ویژه»، «پیشنهاد ممد» — روی گوشی با سوایپ و روی دسکتاپ با دکمه‌های قبلی/بعدی
- فروشگاه با فیلتر دسته، جستجو، مرتب‌سازی و فقط تخفیف‌دارها
- صفحه‌ی محصول با انتخاب نوع آسیاب و تعداد
- سبد خرید (ذخیره در مرورگر)، کد تخفیف، هزینه‌ی ارسال و ارسال رایگان بالای یک مبلغ
- همه‌ی قیمت‌ها سمت سرور حساب می‌شن؛ قیمت از مرورگر قبول نمی‌شه
- منوی پایین مخصوص موبایل

**باشگاه مشتریان**
- عضویت/ورود با موبایل و رمز، امتیاز هدیه‌ی عضویت
- امتیاز بعد از هر پرداخت موفق؛ سطح برنزی / نقره‌ای / طلایی با ضریب امتیاز
- خرج کردن امتیاز موقع پرداخت (با سقف درصدی)؛ اگه پرداخت ناموفق بشه امتیاز برمی‌گرده
- صفحه‌ی حساب: کارت عضویت، پیشرفت سطح، تاریخچه‌ی امتیاز، سفارش‌ها، ویرایش پروفایل

**پنل مدیریت** (`/admin`)
- داشبورد فروش، سفارش‌های منتظر ارسال، موجودی کم، پرفروش‌ها
- محصولات: افزودن / ویرایش / حذف، آپلود عکس، ویرایش سریع قیمت و موجودی، فعال/غیرفعال
- دسته‌بندی‌ها، اسلایدها، کدهای تخفیف
- سفارش‌ها: تغییر وضعیت، کد رهگیری پست، ثبت دستی پرداخت (کارت‌به‌کارت)
- مشتری‌ها: سطح، جمع خرید، افزودن/کسر دستی امتیاز
- تنظیمات: فروشگاه، باشگاه، درگاه‌ها، باسلام، رمز مدیر

## درگاه‌های پرداخت

از «پنل ← تنظیمات ← درگاه‌های پرداخت» فعال کن. آدرس بازگشت (callback) هر درگاه همون‌جا نوشته شده.
`SITE_URL` باید دامنه‌ی واقعی با https باشه.

| درگاه | فایل | چیزی که لازم داری |
|---|---|---|
| زرین‌پال (کارت‌های شتاب) | `lib/payments/zarinpal.ts` | مرچنت کد |
| اسنپ‌پی (اقساطی) | `lib/payments/snappay.ts` | آدرس API، Client ID/Secret، Username/Password (بعد از قرارداد) |
| دیجی‌پی | `lib/payments/digipay.ts` | آدرس API، Client ID/Secret، Username/Password، نوع تیکت |
| درگاه آزمایشی | `lib/payments/mock.ts` | — (فقط تست؛ قبل از فروش واقعی خاموشش کن) |

**مهم:** درگاه زرین‌پال طبق API عمومی نسخه‌ی ۴ نوشته شده. اسنپ‌پی و دیجی‌پی مستندات کاملشون رو فقط بعد از قرارداد می‌دن؛
کدشون طبق جریان استاندارد هر کدوم (token ← ساخت تراکنش ← بازگشت ← verify/settle) نوشته شده و مسیرهای API بالای هر فایل
(`PATHS`) جمع شدن تا اگه با نسخه‌ی مستندات شما فرق داشت، فقط همون‌جا رو اصلاح کنی. قبل از فروش واقعی، هر کدوم رو
در محیط تستی که خودشون می‌دن امتحان کن.

درگاه جدید: یک فایل در `lib/payments/` با اینترفیس `Gateway` بساز و در `lib/payments/index.ts` اضافه‌ش کن.

## باسلام

از «تنظیمات ← باسلام» توکن دسترسی (از developers.basalam.com)، شناسه‌ی غرفه و شناسه‌ی دسته‌بندی رو وارد کن.
بعد تو صفحه‌ی هر محصول «ارسال به غرفه‌ی باسلام» یا تو لیست محصولات «ارسال همه به باسلام» رو بزن.
محصول تو باسلام ساخته یا به‌روز می‌شه (قیمت، موجودی، وزن، توضیحات). عکس رو فعلاً از پنل باسلام اضافه کن.
کد در `lib/basalam.ts` است؛ قبل از استفاده‌ی واقعی با یک محصول تست کن چون API باسلام ممکنه فیلد اجباری بیشتری بخواد.

## ساختار

```
app/(store)/      صفحات فروشگاه (خانه، shop، product، cart، checkout، order، club، account)
app/admin/        پنل مدیریت + server actions
app/api/          quote، checkout، callback درگاه‌ها، سرو عکس‌های آپلودی
lib/db.ts         اسکیمای SQLite  ·  lib/seed.ts  داده‌ی اولیه
lib/orders.ts     محاسبه‌ی قیمت، ثبت سفارش، پرداخت موفق/ناموفق
lib/club.ts       سطح‌ها و امتیاز باشگاه
lib/payments/     درگاه‌ها
components/       اسلایدر، ردیف محصولات، کارت محصول، سبد خرید
```
