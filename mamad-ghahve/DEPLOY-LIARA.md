# راه‌اندازی ممد قهوه روی لیارا

این پروژه روی پلتفرم **Next.js** لیارا اجرا می‌شه. فایل `liara.json` آماده‌ست:

```json
{
  "platform": "next",
  "port": 3000,
  "next": { "nodeVersion": "24" },
  "disks": [{ "name": "data", "mountTo": "data" }]
}
```

- **پورت ۳۰۰۰** و **Node.js 24** (حداقل 22.13)
- **دیسک `data`** روی پوشه‌ی `data` سوار می‌شه. دیتابیس (`shop.db`) و عکس‌های آپلودی (`uploads/`) این‌جا ذخیره می‌شن.
  هر چیزی بیرون از دیسک با هر استقرار یا ری‌استارت پاک می‌شه، پس **بدون دیسک، سفارش‌ها و محصولات از بین می‌رن.**
- **بدون پکیج native:** دیتابیس با موتور SQLite داخلی خود Node.js (`node:sqlite`) کار می‌کنه؛ موقع بیلد چیزی کامپایل یا از GitHub دانلود نمی‌شه،
  پس بیلد روی سرورهای ایران لیارا و با میرور لیارا مشکلی نداره. تو لاگ برنامه ممکنه هشدار `ExperimentalWarning: SQLite` ببینی؛ عادیه و مشکلی نیست.

---

## ۱. ساخت برنامه و دیسک (یک بار)

1. تو [console.liara.ir](https://console.liara.ir) یک برنامه‌ی جدید با پلتفرم **NextJS** بساز (مثلاً با شناسه‌ی `mamad-ghahve`).
   پلن رو حداقل با ۱ گیگ رم انتخاب کن (بیلد Next.js رم می‌خواد).
2. تو صفحه‌ی برنامه ← **دیسک‌ها** ← **ایجاد دیسک**: نام **`data`**، حجم ۱ تا ۲ گیگ.
   (یا با CLI: `liara disk:create -a mamad-ghahve -n data -s 1`)
   نام دیسک باید دقیقاً `data` باشه، چون تو `liara.json` همین نوشته شده.

## ۲. متغیرهای محیطی

صفحه‌ی برنامه ← **تنظیمات** ← **متغیرها**:

| نام | مقدار | توضیح |
|---|---|---|
| `SITE_URL` | `https://دامنه‌ی-شما.ir` | آدرس واقعی سایت با https، بدون `/` آخر. آدرس بازگشت درگاه‌ها از این ساخته می‌شه. |
| `ADMIN_USERNAME` | مثلاً `admin` | نام کاربری اولین مدیر |
| `ADMIN_PASSWORD` | یک رمز قوی | رمز اولین مدیر. فقط بار اول که دیتابیس ساخته می‌شه استفاده می‌شه؛ بعدش از «پنل ← تنظیمات» عوضش کن. |

تا وقتی دامنه وصل نکردی، `SITE_URL` رو همون آدرس پیش‌فرض لیارا بذار (مثلاً `https://mamad-ghahve.liara.run`) و بعد از وصل کردن دامنه عوضش کن و برنامه رو ری‌استارت کن.

کلیدهای زرین‌پال، اسنپ‌پی، دیجی‌پی و باسلام **این‌جا نمی‌رن**؛ از «پنل مدیریت سایت ← تنظیمات» وارد می‌شن و تو دیتابیس (روی دیسک) ذخیره می‌شن.

## ۳. استقرار

### روش الف: CLI (پیشنهادی)

روی کامپیوتر خودت (Node.js نصب باشه؛ تو ویندوز از CMD استفاده کن):

```bash
npm install -g @liara/cli
```
```bash
liara login
```
داخل پوشه‌ی `mamad-ghahve` (همون‌جا که `liara.json` هست):
```bash
liara deploy --app mamad-ghahve
```

پوشه‌های `node_modules`، `.next`، فایل‌های `.env` و دیتابیس محلی طبق `.gitignore` آپلود نمی‌شن.

### روش ب: GitHub

صفحه‌ی برنامه ← استقرار جدید ← اتصال به GitHub ← انتخاب مخزن و شاخه.
چون پروژه داخل پوشه‌ی `mamad-ghahve` در مخزن WebPikasoo هست، باید **مسیر پروژه (root directory)** رو `mamad-ghahve` بدی.
اگه پنل این گزینه رو نداشت، از روش الف یا ج استفاده کن.

### روش ج: آپلود zip

فایل zip پروژه رو تو صفحه‌ی «استقرار جدید» بکش و رها کن. `liara.json` باید تو ریشه‌ی zip باشه (یعنی محتوای پوشه‌ی `mamad-ghahve`، نه خود پوشه).

## ۴. اولین ورود

1. سایت رو باز کن، باید صفحه‌ی اول با محصولات نمونه بیاد. دیتابیس اولین بار خودکار ساخته می‌شه.
2. برو به `/admin` و با `ADMIN_USERNAME` و `ADMIN_PASSWORD` وارد شو.
3. **تنظیمات ← تغییر رمز مدیر**: رمز رو عوض کن.
4. **تنظیمات ← فروشگاه**: نام، تلفن، آدرس، هزینه‌ی ارسال.
5. محصولات نمونه رو با محصولات واقعی عوض کن.

## ۵. دامنه و SSL

صفحه‌ی برنامه ← **دامنه‌ها** ← افزودن دامنه. رکوردهایی که لیارا نشون می‌ده رو تو DNS دامنه‌ات ثبت کن و بعد **«تهیه گواهی SSL»** رو بزن (رایگان و تمدید خودکار).
بعد `SITE_URL` رو به آدرس https جدید تغییر بده و برنامه رو ری‌استارت کن.

## ۶. درگاه‌های پرداخت روی لیارا

- **آدرس بازگشت (Callback):** تو «پنل مدیریت ← تنظیمات ← درگاه‌ها» زیر هر درگاه نوشته شده (از `SITE_URL` ساخته می‌شه).
- **IP ثابت برای اسنپ‌پی (و هر درگاهی که IP می‌خواد):** صفحه‌ی برنامه ← تنظیمات ← **فعال‌کردن IP ثابت**.
  IP نمایش‌داده‌شده رو به اسنپ‌پی بده تا ثبتش کنن. طبق مستندات لیارا این IP اشتراکیه (ممکنه برنامه‌های دیگه هم داشته باشن)؛
  اگه درگاه IP اختصاصی خواست، با پشتیبانی لیارا هماهنگ کن.
- بعد از وارد کردن کلیدها، دکمه‌ی **«تست اتصال»** هر درگاه رو بزن.
- **درگاه آزمایشی رو خاموش کن** (تنظیمات ← درگاه آزمایشی). تا روشنه، هر کسی بدون پرداخت می‌تونه سفارش ثبت کنه.

## ۷. پشتیبان‌گیری

همه‌ی داده‌ها روی دیسک `data` هستن. از بخش دیسک‌ها در پنل لیارا پشتیبان بگیر (یا با FTP دیسک فایل `shop.db` و پوشه‌ی `uploads` رو دانلود کن).
بهتره قبل از هر تغییر بزرگ یک پشتیبان بگیری.

## مشکلات رایج

| مشکل | راه‌حل |
|---|---|
| خطای «به Node.js 22.13 یا بالاتر نیاز داره» | نسخه‌ی Node رو تو لیارا روی ۲۴ بذار (تو `liara.json` هست؛ تو صفحه‌ی استقرار هم قابل انتخابه). |
| تو لاگ بیلد Node یا تنظیمات با `liara.json` فرق داره | یعنی `liara.json` خونده نشده: مطمئن شو پوشه‌ی **`mamad-ghahve`** رو مستقر کردی، نه ریشه‌ی مخزن WebPikasoo. |
| بعد از استقرار، محصولات و سفارش‌ها پاک شدن | دیسک `data` ساخته نشده یا اسمش فرق داره. اسم دیسک باید دقیقاً `data` باشه. |
| ورود به پنل نمی‌شه | `ADMIN_PASSWORD` فقط بار اول اعمال می‌شه. اگه دیتابیس قبلاً ساخته شده، با رمزی که اون موقع بوده وارد شو. |
| درگاه بعد از پرداخت به آدرس اشتباه برمی‌گرده | `SITE_URL` رو درست کن و برنامه رو ری‌استارت کن. |
| عکس‌های آپلودشده بعد از استقرار نیستن | همون مشکل دیسک؛ عکس‌ها تو `data/uploads` ذخیره می‌شن. |
