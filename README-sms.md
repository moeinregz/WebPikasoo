# پنل پیامک + صفحه‌ی سفارش (/o)

## پنل پیامک (داشبورد ← «پنل پیامک»، فقط ادمین)
- **مخاطب‌ها:** همه‌ی شماره‌های موبایل (۰۹…) از CRM (شماره‌ی اصلی و شماره‌های اضافه) و کانال‌ها، به‌صورت خودکار. تلفن ثابت‌ها
  کنار گذاشته می‌شن و هر شماره فقط یه بار میاد.
- **فیلترها:** دسته‌ی صنف (غذا و پذیرایی، سلامت و ورزش، …)، صنف (کافه، رستوران، کلینیک…)، وضعیت تماس (پاسخ نداد، قبول برای دیدن،
  سایت دارد، زنگ نزده، …)، وضعیت سایت در CRM، منبع (CRM/کانال)، جستجو، و حذف کسایی که توی N روز اخیر پیامک گرفتن.
  صنف از «نوع کسب‌وکار» یا اسم کسب‌وکار تشخیص داده می‌شه (همون منطق ساخت سایت خودکار).
- **متن:** «متن جدا برای هر صنف» (برای هر صنفِ انتخاب‌شده یه کادر با متن پیشنهادی همون صنف) یا «یه متن برای همه».
  `{نام}` ← اسم کسب‌وکار، `{لینک}` ← لینک اختصاصی `webpikaso.ir/o/<کد>`. «لغو۱۱» خودکار اضافه می‌شه.
  شمارنده‌ی حرف و تعداد پیامک و پیش‌نمایش زنده کنار هر متن هست؛ متن‌های پیشنهادی همه ۲ پیامکی‌ان.
- **ارسال:** دسته‌های ۲۵تایی با نوار پیشرفت؛ هر ارسال توی «آخرین پیامک‌ها» ثبت می‌شه. «لغو» جلوی هر مخاطب = دیگه پیامک تبلیغاتی نگیره.
- **کمپین‌ها:** تعداد ارسال، ناموفق، **بازدید از صفحه** و **سفارش** برای هر کمپین.
- **پیامک تست:** شماره + متن ← ارسال؛ نتیجه‌ی واقعی پنل (یا خطا) همون‌جا نشون داده می‌شه.

## وصل کردن پنل پیامکی (فراز اس ام اس)
ارسال از `lib/sms.ts` می‌گذره و سرویس‌دهنده‌ی «فراز اس ام اس» (وب سرویس IPPanel) ثبت شده. توی Vercel ← Settings ← Environment Variables:

| متغیر | مقدار |
|---|---|
| `SMS_PROVIDER` | `farazsms` |
| `FARAZSMS_API_KEY` | کلید دسترسی وب سرویس از پنل فراز (بخش «کلیدهای دسترسی وب سرویس») |
| `FARAZSMS_SENDER` | شماره‌ی خط ارسال پنل (مثلاً `3000505` یا `+983000505`) |

بعد از Redeploy، بالای تب «پنل پیامک» وضعیت «وصل به فراز اس ام اس» و اعتبار پنل دیده می‌شه؛ با «پیامک تست» یه ارسال واقعی امتحان کن.
شماره‌ها به شکل `+989…` فرستاده می‌شن و خطای پنل (مثلاً اعتبار کم یا خط نامعتبر) عیناً توی گزارش ارسال ثبت می‌شه.
سرویس‌دهنده‌ی دیگه: یه provider مثل `farazsms` توی `PROVIDERS` اضافه کن.

## صفحه‌ی سفارش `/o` و `/o/<کد>`
- لینک پیامک (`/o/<کد>`) اسم کسب‌وکار رو می‌دونه و روی صنف خودش باز می‌شه: «سلام کلینیک آرامش 👋».
- هیرو با سوال مخصوص همون صنف (مثلاً کلینیک: «هنوز نوبت‌ها رو تلفنی و حضوری می‌گیری؟ مشتری‌های آنلاینت چی؟»).
- **دموی زنده:** قالب لوکس همون صنف با اسم خود کسب‌وکار، داخل قاب موبایل/لپ‌تاپ (`/o/demo/<صنف>?b=<اسم>`).
  دکمه‌های تماس و واتساپ داخل دمو به شماره‌ی وب پیکاسو می‌رسن.
- قبل/بعد، امکانات مخصوص صنف، ۴ قدم، فرم سفارش، سوالات متداول، نوار ثابت موبایل با واتساپ.
- `/o` بدون کد: بازدیدکننده خودش صنفش رو انتخاب می‌کنه (`/o?t=cafe` مستقیم روی کافه باز می‌شه).
- فرم ← تب «سفارش‌ها» (مثل بقیه‌ی درخواست‌ها) و کمپین اون لینک یه «سفارش» می‌گیره.
- صفحه‌ها noindex هستن (صفحه‌ی تبلیغاتی، نه سئو).

صفحه‌های تبلیغاتی کوتاه هر صنف: `/p/<صنف>` (مثلاً `/p/cafe`) — همون فرم سفارش، بدون محتوای اضافه.

فایل‌ها: `lib/sms.ts`، `lib/smsText.ts`، `lib/smsAudience.ts`، `lib/offerContent.ts`، `app/dashboard/SmsPanel.tsx`، `app/o/*`.
